# Guide de contribution

## Workflow
Ce projet suit le **Git Flow** :

1. Crée une issue avant tout travail
2. Crée une branche depuis `develop` : `feature/nom-de-la-feature`
3. Ouvre une Pull Request vers `develop`
4. Attends la review avant de merger

## Conventions de commit
- `feat:` nouvelle fonctionnalité
- `fix:` correction de bug
- `docs:` documentation
- `chore:` maintenance
